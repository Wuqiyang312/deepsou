# 深搜 DeepSou

[English](README.md) | **简体中文**

一个由 DeepSeek 驱动的复古人工搜索引擎。

在这个 AI 搜索框一统天下的年代,我们把 DeepSeek 藏进幕后,让它扮演 1998 年的「人工检索员」:你提出问题,它在大约 2 秒内「翻完整个互联网」,然后交给你一页干干净净的蓝色链接——按照**权威值**从高到低排好序,像早期的搜索引擎那样。

> 深搜一下,你就知道。

## 功能特性

- **复古 Web 1.0 界面**——白底、Times New Roman 蓝色链接、等宽字体注释、灰色门户导航条、跑马灯公告、访客计数器,以及仍然建议 1024×768 分辨率的页脚。
- **CRT 夜视模式**——一键切换到磷光绿 CRT 主题:扫描线、Logo 色差偏移、暗角。选择会被记住。
- **DeepSeek 驱动检索**——支持 `deepseek-chat`(快速)与 `deepseek-reasoner`(深度)两个模型。API Key 只保存在浏览器 `localStorage`,除了 DeepSeek 之外不会发往任何地方。
- **权威值排序**——每条结果带 0–10 的权威值,用老式 PageRank 绿条展示。模型端排一次序,前端再兜底按权威值从高到低排一次。
- **手气不错**——跳过列表直接跳到权威值最高的第一条,老 Google 同款。
- **老式分页**——每页 6 条,「上一页 1 2 3 下一页」。翻页纯前端完成,不重复消耗 API。
- **有生命的复古家具**——雅虎式分类目录、热门搜索榜、真正能留言的留言本、网页快照查看器、带连接测试的设置对话框。
- **演示模式**——未配置 API Key 时,整站用内置示例数据跑完整流程,排序逻辑与正式模式一致,上手零成本。
- **单文件交付**——所有代码都在一个 `index.html` 里,无构建、无框架、无依赖,打开即是 1998。

## 快速开始

```bash
git clone https://github.com/Wuqiyang312/deepsou.git
open deepsou/index.html        # 直接双击打开也可以

# 或者用静态服务器
python3 -m http.server 8000    # 访问 http://localhost:8000
```

## 接入 DeepSeek

1. 点击右上角导航的「API 设置」;
2. 粘贴 DeepSeek API Key(`sk-` 开头),选择模型;使用中继请自行改接口地址;
3. 点「测试连接」验证,再点「保存」。

Key 只存在你自己的浏览器 `localStorage` 中。不配 Key 时站点进入演示模式,演示数据会明确标注。

## 一次搜索是如何发生的

1. 输入关键词(或点击分类目录、热门搜索);
2. 老式「正在人工检索,请稍候……」动画播放的同时,DeepSeek 被要求和 1998 年的检索员一样返回严格 JSON:一段编者按 + 6~10 条结果,每条含 `title`、`url`、`summary` 和 `authority`;
3. 前端按权威值排序、分页,渲染成经典结果块:蓝色标题链接、绿色地址、摘要和权威值绿条;
4. 「快照」打开模拟存档;「手气不错」直接跳转到第一条结果。

## 说明与边界

- 无追踪、无后端:留言本、访客计数、主题、API Key 全部只存在你自己浏览器的 `localStorage`;
- 「设为首页 / 加入收藏」是忠实的时代家具——点击后会一本正经地向你解释,为什么现代浏览器不再允许网页把自己设为主页;
- 尊重 `prefers-reduced-motion`(跑马灯与扫描线自动关闭)。
