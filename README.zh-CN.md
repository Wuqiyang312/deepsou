# 深搜 DeepSou

[English](README.md) | **简体中文**

一个复古的早期互联网风格检索引擎界面——纯前端实现,无后端、无 API Key、无追踪。

输入关键词,本站会「检索」片刻(约 1.4 秒,其中 1.3 秒是怀旧仪式感),然后交给你一页干干净净的蓝色链接——按照**权威值**从高到低排好序,像早期的搜索引擎那样。

> 深搜一下,你就知道。

## 功能特性

- **复古 Web 1.0 界面**——白底、Times New Roman 蓝色链接、等宽字体注释、灰色门户导航条、跑马灯公告、访客计数器,以及仍然建议 1024×768 分辨率的页脚。
- **CRT 夜视模式**——一键切换到磷光绿 CRT 主题:扫描线、Logo 色差偏移、暗角。选择会被记住。
- **权威值排序**——每条结果带 0–10 的权威值,用老式 PageRank 绿条展示,从高到低排列。
- **手气不错**——跳过列表直接跳到权威值最高的第一条,老 Google 同款。
- **老式分页**——每页 6 条,「上一页 1 2 3 下一页」。
- **有生命的复古家具**——雅虎式分类目录、热门搜索榜、真正能留言的留言本、网页快照查看器,以及一本正经解释「设为首页」为何失传的对话框。
- **单文件交付**——所有代码都在一个 `index.html` 里,无构建、无框架、无依赖,双击文件即可回到 1998。

## 快速开始

```bash
git clone https://github.com/Wuqiyang312/deepsou.git
open deepsou/index.html        # 直接双击打开也可以

# 或者用静态服务器
python3 -m http.server 8000    # 访问 http://localhost:8000
```

## 一次搜索是如何发生的

1. 输入关键词(或点击分类目录、热门搜索);
2. 老式「正在查询本地索引库…」动画播放约 1.4 秒;
3. 本地生成 8 条结果——百科、视频、问答、开源、博客等类型,映射到真实知名的站点——权威值从 9.6 依次递减;
4. 结果渲染成经典结果块:蓝色标题链接、绿色地址、摘要和权威值绿条;「快照」打开模拟存档;「手气不错」直接跳转到第一条结果。

## 说明与边界

- 无后端、无 API Key、无追踪:留言本、访客计数、主题全部只存在你自己浏览器的 `localStorage`;
- 结果为本地生成的怀旧演示,权威值为示例打分,并非真实排名信号;
- 尊重 `prefers-reduced-motion`(跑马灯与扫描线自动关闭)。
