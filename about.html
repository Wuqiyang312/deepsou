▍关于本站

About DeepSou · est. 1998 · 复活于 2026

深度搜索 DeepSou 是一个致敬互联网早期时代的检索引擎。

没有算法推荐、没有无尽的信息流。你输入关键词,检索服务翻遍互联网,把结果按权威值排好交给你——像二十年前那样,一条一条,点过去。

本站页面布局参考 2009 年前后的古典搜索引擎:蓝色大标题、搜索框上方的栏目 tab、方方正正的按钮。

—— 站长 敬上,2026 年秋,于赛博阁

▍检索是怎么工作的

1. 浏览器向本站后端 POST /api/search,不直接访问任何外部接口;

2. 后端用服务器端保存的 Key 转发 DeepSeek 网页搜索 API(POST /v1/tools/search),再把结果回传浏览器;

3. 接口为每条结果返回权威性(authority,0–4 分),本站将其折算为 0–10 的权威值,降序排列;

4. authority 未知(-1)时,用 rerank_score(0–3)折算兜底;

5. 服务器未配置 API Key 时,自动切换为本地演示数据(带「本地」标记)。

得分 = authority >= 0 ? authority / 4 * 10 : rerank_score / 3 * 10

▍隐私说明

· 无追踪、无统计脚本、不记录检索日志;

· API Key 只保存在服务器 config.json(已 gitignore),浏览器与第三方均无法读到;

· 搜索请求由本站后端转发,浏览器侧不出现密钥;

· 留言本、夜视模式偏好全部只存在你自己的浏览器里。

▍技术说明

前端为多文件静态页面(无构建、无框架),后端为单个 Node.js 文件,无第三方依赖,Docker 一条命令即可运行。
